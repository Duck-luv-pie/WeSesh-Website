Safe merging

          
Finished work merges itself. Collisions don't.

FAQ

          
Questions, answered

        

        

          

            Which editors does WeSesh work with?
            
VS Code and Cursor. People on either editor can join the same room, so you don't need to agree on one.

          

          

            Which AI agents are supported?
            
Claude Code and Codex. If they're installed, they connect to the room on their own as soon as you start or join one. Support for Cursor's agent is experimental. Each person can use a different agent.

          

          

            Do I have to share my AI account or API keys?
            
No. Everyone uses their own account on their own computer. Your credentials, terminals and agent sign-ins stay local. WeSesh doesn't share terminals and never runs commands on someone else's machine.

          

          

            Can my teammate's prompt run my agent without me knowing?
            
Prompts from a teammate go into the agent terminal WeSesh opened for you, labeled with who sent them, and you get a notification. You can turn friend prompts off at any time, and you can keep your agent's conversation private.

          

          

            What gets shared, and what stays private?
            
Text files in the folder you open. Hidden files like .env, anything in your .gitignore, node_modules, build output, binaries and large files are left out. Keep secrets out of your source files as you normally would.

          

          

            What happens when two agents edit the same file?
            
Each agent works in its own private copy and claims the files it's changing. When work finishes, changes to different lines are merged automatically. If two changes touch the same lines, the overlap waits in Pending Changes for a person to decide.

          

          

            How many people can join, and do we need the same network?
            
Up to four people per room, and you can be on different networks. A local-network mode is also available if you'd rather keep everything on your own network.

          

          

            Does it work with a project I already have cloned?
            
Yes. A friend can join from their existing clone. Matching files are left alone, differences stay as their local changes, and .git and node_modules are never touched.
